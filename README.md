# Vishnu Kant Sharma - Personal Portfolio

Personal portfolio website of **Vishnu Kant Sharma**, Computer Science Student, Python Programmer, and AI/ML Enthusiast.

## Features
- **Personal Identity**: Showcases your background as an ambitious CS student and aspiring developer learning programming from fundamentals.
- **Technical Skills**: Interactive visual cards representing Python, HTML, CSS, JavaScript, Pandas, NumPy, Scikit-learn, Machine Learning, ChromaDB, and RAG.
- **Projects Showcase**:
  1. *Student Performance Prediction AI*: Logistic Regression model predicting student pass/fail results using study hours, attendance, sleep hours, assignment completion, and Instagram usage across 1,000 records.
  2. *College Information RAG Chatbot*: Beginner RAG learning project built with Python and ChromaDB in Google Colab using document chunking and vector storage.
- **What I'm Learning**: Continuous growth tracking across ML, Scikit-learn, Web Development, AI, and Python.
- **Contact Form**: Professional contact form with validation and direct placeholder links.
- **Theme Switcher**: Clean white/light mode default with a true pitch black dark mode toggle.

## Tech Stack
- React
- TypeScript
- Tailwind CSS
